# BlackCat Engine 1.0

BlackCat Engine (BC) is a from-scratch high-performance runtime engine for Minecraft Java Edition 1.12.2. This repository begins with a Forge-independent Java 8 foundation so the microkernel, module runtime, scheduler, event pipeline, asset runtime, compatibility layer, and diagnostics can be tested without Minecraft.

See `docs/superpowers/specs/2026-08-13-blackcat-engine-1.0-design.md` and `docs/superpowers/plans/2026-08-13-blackcat-engine-1.0-foundation.md`.
